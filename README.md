## Цель и задачи

**Цель:** Выявить ключевые факторы (форматы контента, день недели, время суток, интервалы между постами), которые влияют на вовлеченность аудитории, и сформулировать практические рекомендации для оптимизации контент-плана.

**Задачи:**
1.  Собрать и очистить данные о публикациях (719 постов).
2.  Провести разведочный анализ и статистическую проверку гипотез (рубрики, день недели, время суток, интервалы между постами).
3.  Сформулировать бизнес-рекомендации и подготовить письмо для медийной персоны.
4.  *(Дополнительно)* Спроектировать dbt-модели витрины данных для демонстрации навыков работы с SQL.

## Данные и признаки

Источник данных: выгрузка постов паблика `minaev_live` через VK API (`wall.get`): **719 постов** (июнь 2020 — октябрь 2026).
*Датасет не приложен в публичный доступ в целях соблюдения авторских прав на текстовый контент. Код воспроизводит анализ при наличии доступа к VK API.*

**Описание признаков:**
* **Идентификация:** `post_id` (уникальный ID), `is_deleted` (флаг удаления поста).
* **Реакции:** `likes`, `comments`, `reposts` (на их основе считается `total_engagement`).
* **Просмотры:** `views` (используются для расчета ER).
* **Метрики вовлеченности:** `engagement_rate` (ER = total_engagement / views).
* **Время:** `date` (на его основе извлечены `hour`, `weekday` и текст `weekday_ru`).
* **Интервалы:** `days_since_previous_post` (время с момента предыдущего поста).
* **Контентные рубрики:** 10 бинарных флагов (`rubric_...`), полученных через регулярные выражения по тексту поста (`text`).

## Практические выводы

1. **«Серийный номер» и «Личности» — перспективные рубрики для развития.** 
   Это наиболее мощные форматы по силе отклика. «Серийный номер» собирает в 4 раза больше реакций, чем в среднем по каналу. «Личности» показывают второй результат по статистической силе эффекта. Логично начать с разбора топовых выпусков этих рубрик, чтобы выделить повторяющиеся темы и приёмы, а затем протестировать их в других форматах.

2. **Сохранить «Уроки истории» как основу ленты.** 
   Это самая массовая рубрика (28% всех публикаций). Она показывает высокий отклик (ER 3.40%), хотя по силе эффекта немного уступает первым двум. Здесь я бы не советовала резко менять механику — формат уже работает, его лучше развивать эволюционно.

3. **Обратить внимание на «Истории кумиров».** 
   У рубрики ER ниже среднего по каналу, но она статистически значимо выделяется на фоне обычных постов, и этот эффект сохраняется в 2026 году.

4. **Проверить гипотезу с четвергом.** 
   Четверг собирает медианно почти в 4 раза больше реакций, чем среда. Среди перспективных слотов также выделяются 09:00, 13:00, 14:00 и 16:00 МСК. Прежде чем глобально менять контент-план, это стоит проверить A/B-тестом на сопоставимых постах.

5. **Не гнаться за частотой в ущерб качеству.** 
   Посты после пауз более 2 дней собирают больше реакций. Скорее всего, дело не в самой паузе, а в том, что после затишья выходят более крупные и проработанные релизы. Поэтому вместо форсирования ежедневного постинга лучше учитывать масштаб будущих релизов.


## Основные результаты

1. **«Серийный номер» — лидер среди активных рубрик канала по вовлеченности.** N=20, 
   медиана ER **6.18%** (IQR 0.011–0.091), что в 4 раза выше медианы канала (1.5%). 
   Mann-Whitney vs 316 постов без тематических рубрик: p<0.0001, Cliff's δ=**0.649** (большой). Проходит Bonferroni-поправку с большим запасом. Различие статистически значимо и не объясняется случайностью.

2. **Kruskal-Wallis подтверждает неоднородность активных рубрик.**
   H=43.975, p<0.0001, 5 групп [20, 44, 31, 37, 13]. Крайние точки — «Серийный номер» (медиана 5748.5 реакций) vs «ЧТИВО» (медиана 521) — различаются с Cliff's δ=**0.832** (большой). Внутри топ-группы рубрики сильно отличаются друг от друга.

3. **ER по активным рубрикам.** Кроме «Серийного номера» и «Уроков истории» высокий ER показывают: **Личности** — 1.85% (N=44, IQR 0.010–0.088, δ=0.571), **Истории кумиров** — 1.25% (N=37, IQR 0.009–0.047, δ=0.431). **Истории миллиардов** — 0.90% (N=13, IQR 0.005–0.012, δ=0.073, p=0.657) — не отличается от постов без тематических рубрик, но N слишком мал для уверенного вывода. Медиана канала — 1.5%.

4. **«Истории кумиров»** — единственная из трёх протестированных рубрик за период 2026 года, у которой эффект сохраняется vs посты без тематических рубрик:
   - за весь период: δ=**0.431** (средний), p<0.0001.
   - за период 2026 года: δ=**0.477** (большой), p=0.0006.

5. **Самая массовая рубрика** «Уроки истории» — 201 пост (28% канала), ER 3.40% (IQR 0.011–0.070). В Kruskal-Wallis не включена: N=201 несопоставим с остальными (13–44). Тестировалась отдельно vs посты без тематических рубрик: p<0.0001, Cliff's δ=**0.552** (большой). Рубрика значимо отличается от постов без тематических рубрик, но не является лидером. «Серийный номер» и «Личности» обходят её по размеру эффекта.

6. **День недели.** Лучшие — четверг (медиана 2 885.5) и понедельник (2 253). Худший — среда (693), разница с четвергом в 4.2 раза.

7. **Время публикации.** Пиковые слоты в UTC: 06:00 (2554), 11:00 (2447), 13:00 (2290), 10:00 (2208). Провалы: 19:00 (885) и 14:00 (935.5). В МСК это пики **09:00, 14:00, 16:00, 13:00**; провалы **22:00, 17:00**. **Оговорка:** эти значения не контролируются на день недели. Утренние посты часто совпадают с четвергом, поэтому эффект «утра» может быть частично объяснён эффектом «четверга». Рассматривать как зону для A/B-теста. В CSV файле время хранится в UTC: 09:00 МСК = 06:00 UTC.

8. **Интервал между постами.** Spearman rho=+0.274, p<0.0001, n=718. Mann–Whitney «≤2 дня vs >2 дней»: p<0.0001, Cliff's δ=−0.329 (на границе малого и среднего). Чем больше пауза, тем выше реакции на следующий пост. **Оговорка:** это связь, а не причина. Правдоподобная гипотеза: после пауз выходят крупные релизы, и интервал выступает прокси для «крупного контента в подготовке». В данных есть один пост с интервалом 600+ дней (март 2022) — это граница двух режимов паблика. У этого поста низкие реакции относительно канала (215 против медианы 1 400), поэтому он **ослабляет** корреляцию, а не завышает: `rho=0.274` это консервативная оценка снизу.

9. **ER нестабилен** между годами: 2022 — 1.88%, 2023 — 2.18%, 2024 — 5.12% (пик), 2025 — 1.03%, 2026 — 0.64%. ER постов из разных лет может быть несопоставим, поэтому для трех рубрик «Чтиво», «Истории кумиров», «Истории миллиардов» добавлен контрольный тест vs посты без тематических рубрик только за период 2026 года. Без него любой вывод о «слабости» рубрики был бы искажён эффектом временного периода паблика.

## Что не включила в анализ

Длину текста: у видео-постов это длина заголовка, у лонгридов — реального текста, смешивать нельзя. Формат вложений: видео доминирует в выборке, дисбаланс делает тесты маломощными. Внешние ссылки и призывы к действию: несколько процентов, статистически незначимы. Эти признаки проверены и **не включены**.

**Из 10 рубрик в финальный анализ вошли 6.**

**Активные рубрики** (последний пост ≤ 6 мес. назад на дату прогона 2026-10-12). Пять сопоставимых рубрик («Серийный номер», «Личности», «Истории кумиров», «Истории миллиардов», «Чтиво») участвуют в KW и MW. «Уроки истории» (N=201) в KW не включена — тестируется только в MW отдельно.

**Неактивные рубрики** «Простовещи», «Долецкая», «Вторая мировая» остаются в датасете, но исключены из сравнений: их последний пост старше 6 месяцев, контент разных временных периодов канала несопоставим. Список активных рубрик жестко прописан в коде и обновляется вручную при изменении контент-плана.

**«История бренда»** (N=5) не включена в тесты: при таком N мощность Mann-Whitney низкая, а δ будет нестабилен. Рубрика остаётся в датасете, но в KW и MW не участвует.

**«ЧТИВО»** (N=31, ER 0.54%) не отличается от постов без рубрик за 2026 год ни до, ни после Bonferroni-поправки (p=0.17 > 0.05). Cliff's δ=−0.199 — небольшое смещение в худшую сторону. Все посты рубрики вышли в 2026 году, поэтому долгосрочную динамику оценить нельзя.

## Стек

Python: `requests + pandas + scipy + matplotlib + python-dotenv`. Пайплайн реализует полный цикл: «сбор (VK API) → нормализация → статистический анализ → визуализация → сохранение артефактов».

SQL и dbt: В папке models/ представлены `dbt`-модели витрины фактов (`fact_vk_posts.sql` для PostgreSQL и `fact_vk_posts_ch.sql` для ClickHouse) и файл `schema.yaml` с тестами качества. Логика Python полностью воспроизведена на SQL: расчет ER, регулярные выражения для флагов рубрик и оконные функции для интервалов.

Примечание: Развертывание СУБД не выполнялось (фокус на анализе данных), итоговые метрики получены через Python. Однако dbt-код готов к запуску при наличии настроенного `profiles.yml`.

## Быстрый старт (MOCK_MODE)

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корне проекта:
```bash
VK_TOKEN=vk1a.XXXXXXXXXXXXXXXXXXXX
MOCK_MODE=true
```

3. Запустите пайплайн:
```bash
python main.py
```

**Что произойдёт:**
- в режиме `MOCK_MODE=true` скрипт прочитает `mock_data.json` и не пойдёт в VK;
- при `MOCK_MODE=false` и валидном токене выгрузит всю ленту через `wall.get` постранично (100 постов за запрос) с retry и экспоненциальным backoff при `error_code=6` и сетевых ошибках;
- если токена нет или VK API недоступен, то пайплайн **не упадёт**, а деградирует на mock и залогирует причину.

**Артефакты на выходе:**
- `vk_minaev_posts.csv` — чистый датасет (реакции, 10 флагов рубрик, интервал, ER, календарные разрезы). *Датасет не приложен в публичный доступ в целях соблюдения авторских прав на текстовый контент. Скрипт позволяет собрать данные самостоятельно при наличии токена VK API.*
- `engagement_chart.png` — три панели: распределение реакций, медианы по дням недели, медианы по рубрикам;
- сводка метрик, стат-тестов выводится в консоль. Файл `Code_results.txt`.
